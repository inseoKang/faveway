# Raw datasets

FAVEWAY 데이터 파이프라인에서 사용하는 원본 데이터는 이 디렉터리에서 로컬로 관리합니다.

원본 CSV 파일은 재배포 및 저장소 용량 문제를 피하기 위해 Git에 포함하지 않습니다.

## Directory

### `blog/`

블로그 기반으로 수집된 드라마 촬영지 및 배우-작품 관계 데이터입니다.

주요 데이터:

- 드라마별 촬영지
- 촬영지 주소
- 위도 / 경도
- 배우-작품 관계

### `kccf/`

한국문화정보원 기반의 미디어 콘텐츠 촬영지 및 배우-작품 관계 데이터입니다.

주요 데이터:

- 콘텐츠 제목
- 촬영 장소
- 장소 설명
- 주소
- 위도 / 경도
- 미디어 타입
- 배우-작품 관계

## Pipeline

원본 데이터는 직접 수정하지 않습니다.

```text
data/raw
↓
scripts/data-pipeline
↓
outputs/data-expansion
↓
수동 검수
↓
Supabase import
```
